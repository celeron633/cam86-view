# 界面与配置

## 1. 界面布局

界面使用 Qt 6 Widgets，整体保留旧软件三列布局。

### 左列

- 3000×2000 比例的主预览；
- 点击主图选择 50×50 放大位置和 ROI 中心；
- Gain 滑块，范围 0～63；
- Offset 滑块，范围 -127～127。

### 中列

- 顶部日志，可右键清空；
- 中部 50×50 放大图；
- 底部 RGB/灰度对数直方图。

### 右列

- Demo camera / CAM86 libusb 后端选择；
- 连接、bin、ROI、连拍帧数和间隔；
- 曝光、连续采集、GET IMG、STOP 和进度；
- ISO、Information、Output prefix、Write FITS；
- normal/dark/subdark；
- 暗场保存、加载和查看；
- 温度读取、设定和制冷。

窗口默认 1180×720，保留旧版的横向比例。三列通过 QSplitter 调整宽度，默认优先分配空间给主图；主图保持 3:2 并靠上显示。右列通过 QScrollArea 在空间不足时滚动。

Display and files 采用左右两栏：左侧是 ISO 单选按钮，右侧是文件设置和 Normal/Dark/Subdark 单选按钮。再次点击当前 Dark 模式不会清空已经累加的暗场。

界面使用浅灰背景、白色分组和蓝色强调色，样式定义在 `src/ui/theme.qss`。QSS 与控件图标通过 Qt Resource 编入程序，运行时不需要外部样式文件。

## 2. 后端选择

- `Demo camera`：始终可用，无需 USB；
- `CAM86 / libusb`：只有构建时找到 libusb 才可连接真机。

切换后端会先断开当前相机、等待采集线程结束，再替换 `ICamera` 实例。连接或采集期间 UI 禁止切换后端。

## 3. 控件行为

### GET IMG

在已连接且不忙时创建一个 `ExposureRequest` 并开始单帧采集。

### Continuously

打开时帧号归零、下一帧时间设为当前时刻。每帧完成后等待 Delay，再由 UI tick 启动下一帧。

### Frames / Infinite capture

- Infinite capture 关闭：达到 Frames 后停止；
- Infinite capture 开启：忽略 Frames，直到用户关闭连续模式或按 STOP。

### ROI

只改变采集纵向范围。主图最后一次点击位置决定 ROI 中心 Y；X 坐标目前只用于放大图选择。

### Information

每帧完成后计算全帧统计并写入日志。该操作扫描 600 万像素，可能增加帧间处理时间。

### Write FITS / WriteFile

- Write FITS：每帧自动保存；
- WriteFile：立即保存当前 Frame；
- 都使用 Output prefix 加帧号组成文件名。

### Load dark...

使用 `QFileDialog::getOpenFileName()` 打开系统文件选择器，筛选 `.drk` 文件。取消时不修改暗场；文件加载异常写入日志。Windows 文件路径支持 Unicode。

## 4. 事件循环

`QApplication::exec()` 处理控件输入和窗口绘制。QTimer 每 50 ms 调用 `MainWindow::tick()`：

- 拉取控制器日志、温度和完成帧；
- 处理图像、自动保存 FITS、更新统计；
- 空闲时每约 2 s 请求温度；
- 按帧数和间隔调度连拍；
- 刷新控件状态、图像和日志。

相机采集在工作线程完成，Qt 控件只在 UI 线程更新。Stop 在曝光期间和连拍等待间隔均可用。

## 5. 图像绘制

`ImageProcessor` 每次重建或改变选择位置增加 revision。`ImagePanel` 只在 revision 改变时复制 RGBA 缓冲到 QImage，使用 QPainter 显示主图、50×50 局部图和 RGB 对数直方图。图像保持宽高比，点击黑边不会改变选择。局部图使用最近邻缩放以观察像素。

## 6. 配置文件

程序在当前工作目录读写 `cam86.ini`。格式是简单的 `key=value`，不使用 section。当前键：

| Key | 类型 | 含义 |
| --- | --- | --- |
| `simulation` | bool/int | 是否使用 Demo camera |
| `exposure` | int | 曝光选项索引 |
| `offset` | int | Offset UI 值 |
| `gain` | int | Gain UI 值 |
| `iso` | int | ISO 选项索引 |
| `target_temperature` | int | 目标温度 |
| `bin2x2` | bool/int | bin 默认值 |
| `roi` | bool/int | ROI 默认值 |
| `filename` | string | Output prefix |

读取时兼容旧键：

- `exp` 作为 `exposure` 回退；
- `name` 作为 `filename` 回退。

配置对象不保留注释或原始顺序，退出时会重写文件。

## 7. Windows 入口

Windows 目标使用 CMake `WIN32_EXECUTABLE` 和 Qt 入口适配，双击启动不会创建 CMD 窗口。初始化失败时通过 `MessageBoxA` 显示错误。Linux 仍使用普通 `main()`，错误输出到 stderr。

## 8. 旧 Delphi 非可视组件

旧设计器截图底部三个闹钟和文件夹不是运行时按钮：

| 旧组件 | 新实现 |
| --- | --- |
| Timer1 | 曝光 progress callback |
| Timer2 | `MainWindow::tick()` 检查状态和连拍 |
| Timer3 | `steady_clock` 计算帧间 delay |
| OpenDialog1 | `QFileDialog` |
