# 界面与配置

## 1. 界面布局

界面使用 Dear ImGui immediate-mode UI，整体保留旧软件三列布局。

### 左列

- 3000×2000 比例的主预览；
- 点击主图选择 50×50 放大位置和 ROI 中心；
- Gain 滑块，范围 0～63；
- Offset 滑块，范围 -127～127。

### 中列

- 顶部日志，可右键清空；
- 中部 50×50 放大图；
- 底部 RGB/灰度对数直方图。

### 右列

- Demo camera / CAM86 libusb 后端选择；
- 连接、bin、ROI、连拍帧数和间隔；
- 曝光、连续采集、GET IMG、STOP 和进度；
- ISO、Information、Output prefix、Write FITS；
- normal/dark/subdark；
- 暗场保存、加载和查看；
- 温度读取、设定和制冷。

右列宽度按窗口约 22.5% 分配，并限制在 250～310 像素；窗口不足时使用垂直滚动。

## 2. 后端选择

- `Demo camera`：始终可用，无需 USB；
- `CAM86 / libusb`：只有构建时找到 libusb 才可连接真机。

切换后端会先断开当前相机、等待采集线程结束，再替换 `ICamera` 实例。连接或采集期间 UI 禁止切换后端。

## 3. 控件行为

### GET IMG

在已连接且不忙时创建一个 `ExposureRequest` 并开始单帧采集。

### Continuously

打开时帧号归零、下一帧时间设为当前时刻。每帧完成后等待 Delay，再由 UI tick 启动下一帧。

### Frames / Infinite capture

- Infinite capture 关闭：达到 Frames 后停止；
- Infinite capture 开启：忽略 Frames，直到用户关闭连续模式或按 STOP。

### ROI

只改变采集纵向范围。主图最后一次点击位置决定 ROI 中心 Y；X 坐标目前只用于放大图选择。

### Information

每帧完成后计算全帧统计并写入日志。该操作扫描 600 万像素，可能增加帧间处理时间。

### Write FITS / WriteFile

- Write FITS：每帧自动保存；
- WriteFile：立即保存当前 Frame；
- 都使用 Output prefix 加帧号组成文件名。

### Load dark...

打开项目内置 ImGui 文件选择器：

- 支持 Up、Refresh；
- 目录优先排序；
- 只显示 `.drk` 文件；
- 支持双击或 Open；
- 不调用 Windows 专有文件对话框。

## 4. 主循环

每个窗口帧的逻辑顺序：

```text
glfwPollEvents()
  → MainWindow::tick()
      ├─ 拉取控制器日志
      ├─ 拉取温度
      ├─ 拉取完成帧并处理
      ├─ 空闲时每约 2 s 请求温度
      └─ 判断是否启动下一张连拍
  → ImGui NewFrame
  → MainWindow::draw()
  → OpenGL render
  → swap buffers
```

相机线程不会直接操作 ImGui 或 OpenGL。

## 5. OpenGL 纹理更新

`ImageProcessor` 每次重建后增加 revision。`ImagePanel` 只在 revision 改变时上传：

- 900×600 主预览纹理；
- 50×50 局部纹理。

主图使用线性缩小和最近邻放大组合；局部图使用最近邻效果观察原像素。

## 6. 配置文件

程序在当前工作目录读写 `cam86.ini`。格式是简单的 `key=value`，不使用 section。当前键：

| Key | 类型 | 含义 |
| --- | --- | --- |
| `simulation` | bool/int | 是否使用 Demo camera |
| `exposure` | int | 曝光选项索引 |
| `offset` | int | Offset UI 值 |
| `gain` | int | Gain UI 值 |
| `iso` | int | ISO 选项索引 |
| `target_temperature` | int | 目标温度 |
| `bin2x2` | bool/int | bin 默认值 |
| `roi` | bool/int | ROI 默认值 |
| `filename` | string | Output prefix |

读取时兼容旧键：

- `exp` 作为 `exposure` 回退；
- `name` 作为 `filename` 回退。

配置对象不保留注释或原始顺序，退出时会重写文件。

## 7. Windows 入口

Windows 目标使用 CMake `WIN32_EXECUTABLE` 和 `wWinMain`，双击启动不会创建 CMD 窗口。初始化失败时通过 `MessageBoxA` 显示错误。Linux 仍使用普通 `main()`，错误输出到 stderr。

## 8. 旧 Delphi 非可视组件

旧设计器截图底部三个闹钟和文件夹不是运行时按钮：

| 旧组件 | 新实现 |
| --- | --- |
| Timer1 | 曝光 progress callback |
| Timer2 | `MainWindow::tick()` 检查状态和连拍 |
| Timer3 | `steady_clock` 计算帧间 delay |
| OpenDialog1 | `ui::FileDialog` |
