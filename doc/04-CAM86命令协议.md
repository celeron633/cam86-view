# CAM86 命令协议

## 1. 协议层次

CAM86 控制不是标准 USB class 命令。应用先通过 FTDI vendor request 把通道 B 配成异步 bit-bang，再把 SPI/GPIO 时序编码为普通 bulk OUT 字节：

```text
CAM86 command
  → command + 16-bit parameter
  → 100-byte GPIO waveform
  → FT2232H channel B bulk OUT
  → 相机控制器
```

响应通过同一通道 B 的 bulk IN 采样 GPIO 电平，再恢复为 16 位值。

## 2. GPIO 基值和位含义

控制波形的空闲字节为 `0x11`。移植自旧 `Cam86.pas` 的位操作包括：

- `0x20`：每位第二个采样点拉高时钟；
- `0x80`：当前待发送数据位为 1 时，在两个采样点上拉高；
- `0x40`：响应输入采样位；
- AD9822 波形另外使用 `0x01`、`0x02`、`0x04` 控制片选/时钟/数据组合。

这些是从旧代码行为还原的逻辑定义，具体引脚与硬件原理图的对应关系仍应在真机联调时确认。

## 3. 通用 SPI 命令帧

`makeSpiWaveform(command, parameter)` 将三个字节按 MSB first 编码：

```text
byte 0: command
byte 1: parameter[15:8]
byte 2: parameter[7:0]
```

每个数据位占两个输出字节，三字节有效波形占前 48 字节；总传输固定为 100 字节，其余维持空闲值。这与旧版 `sspi` 保持一致。

`spiCommand()` 的完整过程：

1. purge B 通道 RX/TX；
2. 生成 100 字节输出波形；
3. 写 B bulk OUT，超时 100 ms；
4. 读 B 的 100 字节有效 payload，超时 100 ms；
5. 解码 16 位返回值；
6. 等待 20 ms。

## 4. 响应采样

旧 Delphi 缓冲区声明为 `Word[]`，但 `FT_Read` 按字节写入，因此表达式 `FT_In_Buffer[i+9]` 实际采样的是字节偏移 `18 + i×2`。新版为保持协议行为，在 16 个位置检查 `0x40`：

```text
18, 20, 22, ..., 48
```

每次先左移，再按采样电平写入最低位，最终得到 16 位 MSB-first 结果。

## 5. CAM86 命令表

| 命令 | 参数 | 当前用途 | 调用时机 |
| ---: | --- | --- | --- |
| `0xDB` | `0` | 相机/控制器初始化 | 连接阶段 |
| `0x4B` | 起始传感器行 ÷ 2 | 设置采集起始行对 | 每次曝光前 |
| `0x5B` | 采集传感器行数 ÷ 2 | 设置采集行对数量 | 每次曝光前 |
| `0x8B` | `0`/`1` | 关闭/启用 2×2 bin | 每次曝光前 |
| `0x6B` | 曝光毫秒，最大写入 `1001` | 设置短曝光或长曝光前段 | 每次曝光前 |
| `0x2B` | `0` | 长曝光准备，旧注释 `shift3` | 曝光大于 1 s |
| `0xCB` | `0` | 清帧 | 长曝光准备 |
| `0x3B` | `0` | 旧注释 `off 15v` | 长曝光开始前 |
| `0x1B` | `0` | 触发帧读出 | 图像 IN 已经挂起后 |
| `0xBF` | `0` | 读取温度 | 空闲时约每 2 s 或手动 |
| `0xAB` | `1280 + round(T×10)` | 设置目标温度 | 温度滑块改变 |
| `0x9B` | `0`/`1` | 关闭/开启制冷 | Cooling 切换 |

命令语义来自旧 Delphi 代码。没有固件源码时，不能进一步保证命令名、单位和边界在所有 CAM86 固件版本上完全一致。

## 6. 温度编码

温度使用偏移量 1280 和 0.1 °C 单位：

```text
设置：raw = 1280 + round(celsius × 10)
读取：celsius = (raw - 1280) / 10
```

读取结果若超出 `[-120, 120] °C`，视为异常，返回最近一次有效缓存值。

## 7. AD9822 波形

AD9822 不走通用 CAM86 命令，而是由 `makeAd9822Waveform(address, value)` 直接生成 64 字节 GPIO 波形：

- 地址为 3 位；
- 数据按 9 位处理；
- 输出经通道 B bulk OUT 发送；
- 当前不读取 AD9822 返回值。

寄存器使用：

| 地址 | 数据 | 用途 |
| ---: | --- | --- |
| `0` | 连接时 `0xD8` | AD9822 初始化 |
| `3` | `0..63` | Gain |
| `6` | 符号编码后的 Offset | Offset |

Offset 先限制到 `[-127, 127]`，编码规则为：

```text
magnitude = abs(2 × offset)
offset < 0 时 encoded = magnitude + 256
```

## 8. 连接初始化序列

```text
打开 0403:6010、serial CAM86*
  → B: bit mode 0x04, mask 0xBF
  → B: 20000 baud
  → A/B: latency 1 ms
  → purge A/B
  → AD9822 register 0 = 0xD8
  → gain = 0
  → offset = -6
  → wait 100 ms
  → command 0xDB, 0
  → wait 100 ms
  → purge A RX
  → Ready
```

UI 中保存的 Gain/Offset 不会在 `Cam86Camera::connect()` 内自动替代初始化值；连接后控件变化才会再次写入。这一点可在后续真机版本中改进。
