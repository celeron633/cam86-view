# 项目概述

## 1. 项目目标

CAM86-View 是旧 Delphi 7 CAM86 相机控制软件的现代 C++20 重构。主要目标是：

- 使用 Dear ImGui 重建桌面界面；
- 使用 CMake 管理 Windows 和 Linux 构建；
- 将 UI、相机控制、USB 通信和图像处理拆分为独立模块；
- 尽量保持旧软件的界面布局和使用习惯；
- 用 libusb 替换只支持 Windows 的 `FTD2XX.DLL`；
- 在没有相机的情况下通过模拟后端验证主要功能。

## 2. 功能范围

当前实现包括：

- CAM86 连接和断开；
- Gain、Offset 和 AD9822 初始化；
- 从 0 ms 到 30 min 的曝光选择；
- 全画幅和纵向 ROI 采集；
- 2×2 bin；
- 单帧和连续采集；
- 制冷开关、目标温度设置和传感器温度读取；
- Bayer 彩色预览或 bin 后灰度预览；
- 固定 ISO 位移或自动黑白场拉伸；
- 50×50 局部放大图、RGB/灰度直方图和图像统计；
- 暗场累加、保存、载入、查看和扣除；
- 16 位 FITS 输出；
- 跨平台 ImGui 文件选择器；
- Demo camera 模拟图像源；
- 工作目录 `cam86.ini` 配置保存。

## 3. 旧工程与新工程的对应关系

| Delphi 7 | 新 C++ 实现 | 说明 |
| --- | --- | --- |
| `Unit1.pas/.dfm` | `src/ui/`、`src/app/` | 窗口、控件事件、Timer 行为 |
| `Cam86.pas` | `src/camera/Cam86Camera.cpp` | 相机命令、曝光和帧解码 |
| `MyD2XX.pas` | `src/usb/` | D2XX 被 libusb FTDI 后端替代 |
| `ImCam.pas` | `src/image/` | Bayer、显示映射、统计、暗场、FITS |
| `TTimer1` | 曝光线程的 progress callback | 曝光进度 |
| `TTimer2` | UI `tick()` + `CameraState` | 连拍状态检查 |
| `TTimer3` | `std::chrono::steady_clock` | 连拍间隔 |
| `TOpenDialog` | `ui::FileDialog` | 加载 `.drk` 文件 |

## 4. 关键数据规格

| 项目 | 当前值 |
| --- | --- |
| 传感器宽度 | 3000 像素 |
| 传感器高度 | 2000 像素 |
| 原始像素 | 16 位无符号整数 |
| Bayer 排列 | GRBG，即 `G R / B G` |
| 预览分辨率 | 900×600 RGBA |
| 局部放大区域 | 50×50 像素 |
| 默认 FTDI VID/PID | `0403:6010` |
| USB serial 筛选 | 以 `CAM86` 开头 |
| 控制通道速率 | 20,000 baud 的 FTDI 异步 bit-bang |

## 5. 术语

- **通道 A**：FT2232H interface 0，主要用于 CCD 图像 bulk IN。
- **通道 B**：FT2232H interface 1，异步 bit-bang 控制通道。
- **SPI 命令**：由软件生成 GPIO 波形发送给 CAM86 控制器的 1 字节命令加 2 字节参数。
- **行对**：CAM86 每次按两条传感器行组织数据，帧大小也按行对计算。
- **bin 2×2**：硬件返回每个 2×2 区域的一个样本，软件再扩展到 3000×2000 显示缓冲区。
- **ISO**：旧软件沿用的显示位选择名称，不是相机感光度；本质是 16 位值的右移量。

## 6. 已知边界

项目已经完成编译、单元测试和模拟采集验证，但尚未连接真实 CAM86。因此以下内容属于“从旧代码推导并实现”，还不是“实机确认”：

- EEPROM 中实际 VID/PID 和 serial；
- FT2232H B 通道 bit-bang 的真实电气时序；
- bin 模式每个行对头部的确切字数；
- 长曝光停止时硬件是否需要额外中断命令；
- 不同固件版本是否使用相同命令字。

具体联调方法见 [10-真机联调与排错](10-真机联调与排错.md)。
