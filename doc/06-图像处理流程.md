# 图像处理流程

## 1. 处理目标

图像处理层同时保留两种数据：

- `Frame::pixels`：3000×2000、16 位原始/暗场校正数据，用于统计和 FITS；
- 8 位 RGBA 缓冲区：用于 QImage 显示。

科学数据与显示数据分离，调整 ISO 或自动拉伸只会重建预览，不会改变 16 位 Frame。

## 2. 总体流程

```text
Frame(uint16)
  → accept()
      ├─ Normal：直接保存
      ├─ Accumulate：累加暗场
      └─ Subtract：扣除暗场并加 pedestal
  → rebuild(monochrome, isoShift)
      ├─ 计算显示黑白场
      ├─ Bayer 双线性插值或灰度
      ├─ 映射到 8 bit
      ├─ 生成 900×600 RGBA
      ├─ 生成 RGB/灰度直方图
      └─ 更新 50×50 RGBA 放大图
```

暗场细节见 [07-暗场与FITS](07-暗场与FITS.md)。

## 3. Bayer 排列

当前传感器按 GRBG 解释：

```text
y 偶数: G R G R ...
y 奇数: B G B G ...
```

位置判断：

| y 奇偶 | x 奇偶 | 颜色 |
| --- | --- | --- |
| 偶 | 偶 | G（R 行） |
| 偶 | 奇 | R |
| 奇 | 偶 | B |
| 奇 | 奇 | G（B 行） |

依据来自旧 `TMyImage.Bayer` 的样本位置和新版帧解码顺序。

## 4. 双线性去马赛克

实现入口为 `ImageProcessor::bayerAt(x, y)`。不同像素位置的估算如下。

### R 位置

```text
R = center
G = (left + right + up + down) / 4
B = (四个对角) / 4
```

### B 位置

```text
B = center
G = (left + right + up + down) / 4
R = (四个对角) / 4
```

### G 位置

根据 G 位于 R 行还是 B 行，R/B 分别从水平方向或垂直方向两个邻点平均。

边界通过 `clampSample()` 将坐标限制到有效范围，不需要为四边和四角维护大量单独分支。与旧版相比，这种写法更容易审查，但仍属于基础双线性算法，不包含白平衡、色彩矩阵、坏点修复或边缘感知插值。

## 5. bin 模式显示

UI 调用：

```cpp
image.rebuild(bin2x2, isoShift);
```

因此 `bin2x2 == true` 时按 monochrome 路径显示，单个 16 位样本复制到 RGB 三通道；unbinned 时执行 GRBG 去马赛克。

这与旧版行为一致：旧代码 bin 时调用 `Ris()`，非 bin 时调用 `Bayer()` + `RisRGB()`。

## 6. ISO 位移显示

旧界面中的 ISO 是选择 16 位数据的连续 8 位窗口。新版把选项映射为右移量：

| UI | `isoShift` | 输出近似 |
| --- | ---: | --- |
| `8..15` | 8 | `value >> 8` |
| `7..14` | 7 | `value >> 7` |
| ... | ... | ... |
| `0..7` | 0 | 原最低 8 位，超过 255 截断 |
| `auto` | -1 | 自动黑白场线性拉伸 |

右移后结果限制到 `[0,255]`。

## 7. 自动黑白场

自动模式建立 65536 桶直方图，从低端和高端分别累计。阈值为 3000 个像素，即传感器宽度：

```text
blackLevel = 低端累计未达到 3000 的最后一个值
whiteLevel = 高端累计未达到 3000 的最后一个值
```

显示映射：

```text
mapped = (value - blackLevel) × 255 / (whiteLevel - blackLevel)
mapped clamp 到 [0,255]
```

若黑白场相同，强制 `whiteLevel = blackLevel + 1`，避免除零。该算法延续旧 `CalkGis` 的裁剪思路，能够忽略少量极暗/极亮异常值。

## 8. 预览降采样

主显示缓冲固定为 900×600 RGBA。每个预览坐标采用最近邻映射：

```text
sensorX = previewX × 3000 / 900
sensorY = previewY × 2000 / 600
```

只对预览采样点执行 Bayer 插值，避免每次都生成完整 3000×2000 RGB 图，降低 CPU 和显存带宽需求。

预览内存约为：

```text
900 × 600 × 4 = 2,160,000 bytes
```

## 9. 50×50 放大图和选区

用户点击主图后，归一化坐标转换为传感器坐标。以选中位置为中心取 50×50，边缘处将起点限制在有效范围。

放大图使用与主预览相同的：

- Bayer/灰度模式；
- ISO/自动黑白场映射；
- RGBA 格式。

显示时 QPainter 采用最近邻放大，以保留像素块观察效果。

## 10. 直方图

在生成 900×600 预览时同步统计 256 桶 R/G/B 直方图，而不是扫描完整 600 万像素。绘图前使用：

```text
height = log(1 + count)
```

对数显示能同时看到高频背景和低频亮部。灰度模式三个通道相同，曲线会重合。

## 11. 图像统计

开启 Information 后计算：

- 全帧平均值、总体标准差、最小值和最大值；
- 从第 500 行起连续两行的标准差；
- 根据 GRBG 原始位置计算 R、G、B 样本均值。

统计扫描完整 600 万像素，明显比普通预览更耗时，因此默认关闭。

## 12. 当前没有实现的处理

- 白平衡和 RGB 增益；
- 色彩校正矩阵/gamma；
- 坏点、热像素和宇宙线消除；
- 边缘感知或高质量去马赛克；
- 平场校正；
- 实时堆栈；
- GPU shader 图像处理。

新增算法时应继续保持 16 位 Frame 不被显示过程破坏，并为纯算法增加小尺寸合成测试。
