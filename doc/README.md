## 当前实现状态

- Windows 下已验证 MSVC 构建，包括启用和禁用 libusb 两种配置。
- 核心测试覆盖 FTDI 状态头剥离、SPI 波形、SPI 响应、bin/unbin 帧解码以及模拟相机图像链路。
- Demo camera 可用于无硬件的 UI、曝光、连拍、暗场、图像处理和 FITS 流程测试。
- 仓库环境没有 CAM86 实机，因此 FT2232 EEPROM 参数、电气时序和真实传感器帧头仍需要真机确认。

## 文档维护约定

修改下列代码时，应同步更新对应文档：

- `src/usb/` 或 `include/cam86/usb/`：更新 03；
- `src/camera/Cam86Camera.cpp`：更新 04 和 05；
- `src/image/`：更新 06 和 07；
- `src/ui/` 或 `src/app/AppState.hpp`：更新 08；
- `CMakeLists.txt`、presets 或依赖：更新 09；
- 取得真机验证结果后：更新 10，并把确认项回填到 03～05。
